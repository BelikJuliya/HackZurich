# HackZurich
The application needs a server laptop connected to the same wifi to work

Приложение чат - бот страховой компании, работающее на базе AI. Чат боту можно описать свою проблему при наступлении страхового случая и проконсультироваться касательно выплат по своему страховому договору. 
На бекенде работает нейросеть, которая изучает страховой договор конкретного польхователя и выдают через мобильный клиент ответы касательно предусмотренных выплат и условий договора.

Технологический стек: XML + AdapterDelegates with ListAdapter, MVVM + LiveData, Coroutines, Hitl DI, Glide, Chucker
